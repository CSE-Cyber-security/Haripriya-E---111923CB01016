# 🔢 Fibonacci Series in C

## 📌 Project Description

This project is a simple C program that generates and prints the Fibonacci series for a given number of terms.

The **Fibonacci series** is a sequence in which each number is the sum of the two preceding numbers. The series starts with `0` and `1`.

## 💻 Sample Input and Output

**Input:**
```text
Enter the number of terms: 7
```

**Output:**
```text
Fibonacci Series: 0 1 1 2 3 5 8
```

## ⚙️ Algorithm

1. Start the program.
2. Read the number of terms from the user.
3. Initialize the first two Fibonacci numbers as `0` and `1`.
4. Print the Fibonacci numbers up to the specified number of terms.
5. Calculate each subsequent number by adding the previous two numbers.
6. Repeat until the required number of terms is printed.
7. Stop the program.

## 🛠️ Technologies Used

- **Programming Language:** C
- **Compiler:** GCC
- **Platform:** Windows, Linux, and macOS
